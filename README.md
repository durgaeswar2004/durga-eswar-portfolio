# Durga Eswar Portfolio — HTML, CSS & JavaScript

A responsive, photo-free personal portfolio for Durga Eswar, Quality Team Coach with four years of experience at One Point One Solutions Pvt. Ltd.

## Run locally
1. Extract the ZIP folder.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. No build step or npm install is required.

## Files
- `index.html` — website structure and content
- `style.css` — layout, responsive design, and visual styling
- `script.js` — navigation, reveal animations, email copy, and current year
- `resume.pdf` — updated resume provided by the user
- `six-sigma-yellow-belt-certificate.pdf` — course certificate provided by the user

## Resume and certificate
The Resume section links to `resume.pdf`. The Certification section links to the Six Sigma Yellow Belt certificate PDF. Keep both PDFs in the same folder as `index.html`.

## Before publishing
- Review the contact details and all resume content.
- The website includes work experience and skills from the supplied resume, plus the supplied Six Sigma Yellow Belt certificate.
- Icons and fonts use online CDNs, so those assets require an internet connection.
